# SmartSurf Companion public UI sources

Curated browser-side Companion pages and marketing templates from the SmartSurf Rider application. These sources expect the corresponding SmartSurf API and existing site assets; they are not a standalone backend deployment.

- `public-smartsurf/`: rider, activation, billing, account and administrative browser interfaces, styles and curated assets.
- `website/`: public marketing templates and generated page sources.

Backend implementation, production configuration, account records, telemetry, credentials and operational reports remain private. A rendered UI is not evidence of field validation. Keep current and in-development capabilities labelled as in the source pages.

Third-party notices remain alongside the bundled React and LiveKit assets. See the repository license and notice files for the existing public project terms.
